Tabs

Two variants. default is the underlined navigation bar — a faint gray-200 baseline with the selected tab's gray-1000 underline riding over it. secondary is a compact pill segmented control. Labels are Title Case nouns; active text is ink, inactive is gray-900.

Default — underline navigation

Overview content sits here. The selected tab carries the 2px ink underline; inactive tabs are gray-900 and shift to ink on hover. The disabled tab keeps its colour but shows a not-allowed cursor.

48px track · 24px column gap · 14px / weight 400 · underline 2px gray-1000 over a gray-200 baseline.

Secondary — pill segmented

Compact 24px pills. The selected pill fills gray-1000 with inverted text; inactive pills sit on a translucent gray-alpha-200 fill.

24px height · 8px gap · 13px / weight 400 · selected = gray-1000 fill + inverted text · no baseline rule.
